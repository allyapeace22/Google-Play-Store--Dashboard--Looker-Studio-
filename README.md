# Google Play Store Analytics Dashboard – Looker Studio

## Project Overview

This project focuses on analyzing Google Play Store application data using **Google Looker Studio**. The objective is to understand app performance, installation trends, category distribution, content ratings, and pricing preferences through an interactive dashboard.

The dashboard helps transform raw application data into meaningful business insights that can support data-driven decision-making.

## Business Problem

The objective of this project is to help management understand:

- Which app categories receive the highest number of installs?
- How are app updates distributed over time?
- Which content-rating groups have the highest installs?
- What is the distribution of free and paid applications?
- Which applications have the highest number of installs?
- What is the overall average app rating?

## Dataset Information

- **Dataset:** Google Play Store Dataset
- **File Name:** googleplaystore_clean.xlsx
- **Data Source:** Google Sheets
- **Data Fields:** App, Category, Rating, Reviews, Size, Installs, Type, Price, Content Rating, Genres, Android Version, Current Version, Last Updated.

## Tools and Technologies

- **Google Looker Studio:** Dashboard development and data visualization.
- **Google Sheets:** Dataset import and data connection.
- **Microsoft Excel:** Dataset handling and preparation.

## Dashboard KPIs

The dashboard includes five Key Performance Indicators (KPIs):

| KPI | Description |
|---|---|
| Total Apps | Total number of application records |
| Total Installs | Total installs across applications |
| Average Rating | Average rating of applications |
| Free Apps | Count of free applications |
| Paid Apps | Count of paid applications |

## Visualizations Developed

### 1. Top 10 Categories by Installs
A bar chart showing the application categories with the highest number of installs.

**Purpose:** Identify popular app categories and understand installation distribution.

### 2. App Updates Over Time
A time-series chart showing application installs against the Last Updated date.

**Purpose:** Explore the relationship between app update dates and installation distribution over time.

### 3. Installs by Content Rating
A bar chart comparing installs across different content-rating groups.

**Purpose:** Understand installation distribution across different audience-rating categories.

### 4. Free vs Paid Apps
A pie chart comparing the proportion of free and paid applications.

**Purpose:** Understand application pricing distribution.

### 5. Top 5 Apps by Installs
A bar chart displaying the five applications with the highest install counts.

**Purpose:** Identify the most popular applications in the dataset.

## Project Workflow

1. Obtained the cleaned Google Play Store dataset.
2. Imported the Excel dataset into Google Sheets.
3. Connected Google Sheets to Google Looker Studio.
4. Configured dimensions and metrics for the visualizations.
5. Created five KPI scorecards.
6. Developed five charts to analyze app performance.
7. Applied filters, sorting, labels, titles, and colour formatting.
8. Arranged the visualizations into a single dashboard.
